# Sagar Kumar — Academic & Research Portfolio

Personal website and academic research portfolio for **Sagar Kumar** (Assistant Professor at Poornima University, Jaipur, and Founder & CEO of Kosmatron), hosted on **GitHub Pages**.

🔗 **Live Website**: [https://sagarkumar.github.io](https://sagarkumar.github.io)

## 🔬 Research Focus & Themes

1. **Quantum Computing & Algorithms**: Variational quantum algorithms (VQE), quantum simulation of protein folding energy landscapes, and quantum game theory (Neo-Nash).
2. **Quantum Machine Learning (QML)**: Hybrid quantum-classical deep neural networks, parameterized quantum circuits with PennyLane and Qiskit, end-to-end PyTorch training, disease prediction, and quantum biomarker discovery.
3. **Quantum Space Technology**: Computing systems for cosmology and astrophysics; patented computing system for in-orbit simulation of black holes and early-universe dynamics, neutrino oscillation modeling, and research via Kosmatron.
4. **Machine Learning & Data Science**: Lightweight CNN architectures for edge diagnostics, time-efficient K-Means clustering, and financial sentiment analysis via Large Language Models.
5. **Android & Full-Stack Systems**: Production-grade Kotlin Android architecture (SmartCampus) and MEAN-stack learning management portals (AcademiQ).

```text

```

## 🛠️ Technology Stack

- **Core**: Semantic HTML5, Vanilla CSS3, Modern ES6+ JavaScript (ES Modules).
- **Design System**: *Modernist* architectural aesthetic (strict 0px corner radii, OKLCH tonal palette, high-contrast typography in Google Font **Archivo**).
- **Procedural SVGs**: Custom vector graphics rendered in mathematical precision via code (Bloch spheres, 4-qubit quantum circuits with dynamic pulse animations, neural topologies, and interactive bipartite research maps).
- **Zero Heavy Dependencies**: 100% dependency-free client-side code; no external build step required; instantly served by GitHub Pages or any static file server.

## 🚀 Running Locally

To run the site locally for development or inspection, use any standard static server:

### Option 1: Python 3 (Built-in)
```bash
python3 -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.

### Option 2: Node.js (npx serve)
```bash
npx serve .
```
